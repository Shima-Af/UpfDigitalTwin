# UPFDigitalTwinEnv

Measurement-grounded digital twin environment for evaluating 5G UPF configuration actions under real and forecasted traffic.

This repository consumes:
- UPF profiling models from UpfProfilingCampaign
- cluster-level traffic artifacts from UpfTrafficForecaster

It provides a controller-agnostic environment for what-if analysis, baseline policies, and future RL-based control.
